    Module 01

    Leren denken als een programmeur

    Welkom bij de eerste programmeermodule met Python.

    In deze module leer je niet alleen code schrijven. Je leert hoe je een probleem onderzoekt, een oplossing ontwerpt en deze vertaalt naar instructies die een computer kan uitvoeren.

    Je werkt met Python, maar programmeren begint hier niet achter het toetsenbord. Iedere week start met denken, onderzoeken, bespreken en zichtbaar maken hoe je een probleem aanpakt.

    Zo volg je deze module

    Iedere week werk je volgens een vaste werkwijze.

    Thinking Set — TSET

    Een Thinking Set is een samenhangende verzameling denkactiviteiten.

    Tijdens een TSET onderzoek je samen het probleem van de week. Je werkt meestal staand aan een whiteboard, bespreekt verschillende mogelijkheden en maakt je aanpak zichtbaar.

    Het doel is niet om direct de juiste code te schrijven. Eerst probeer je te begrijpen wat het probleem vraagt en hoe een mogelijke oplossing kan werken.

    Concepten

    Tijdens het werken kom je programmeerconcepten en denkstrategieën tegen die je nodig hebt om verder te komen.

    De conceptpagina's vormen samen een kennisbank. Je gebruikt deze uitleg wanneer je kennis wilt opzoeken, verdiepen of opnieuw bekijken.

    Problem Set — PSET

    Een Problem Set is een samenhangende verzameling programmeeropdrachten.

    In een PSET pas je toe wat je hebt onderzocht en geleerd. Je ontwerpt oplossingen, schrijft Python-code, test je programma en verbetert je uitwerking.

    Portfolio

    Je bewaart je ontwerpen, code, resultaten en reflecties in je portfolio.

    Daardoor ontstaat gedurende de module een overzicht van je werk en van de ontwikkeling die je hebt doorgemaakt.

    Het woord set betekent hier een samenhangende verzameling opdrachten of activiteiten die bij elkaar horen.

    De werkwijze

    Thinking Set  →  Concepten  →  Problem Set  →  Portfolio
      ↑                 ↘          ↓
      └────────────────────────────┘

    Deze route helpt je om iedere week te weten waar je begint en waar je naartoe werkt. Je mag tijdens het werken altijd teruggaan naar een eerdere stap.
